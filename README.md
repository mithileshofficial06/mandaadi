# Mandaadi

A 90-second daily sailing race inside a Reddit post. Everyone in the subreddit sails the same course in the same wind. You can't sail straight into the wind, so the puzzle is your line: left or right, chase the gust, tack now or later.

On the Tamil coast, the *mandaadi* is the sailor who leads the crew in traditional sailboat races: the one who reads the wind and picks the line.

Built for Reddit's Daily Games Hackathon on Devvit Web. Work in progress.
