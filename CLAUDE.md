# Mandaadi: rules for agents

A daily sailing race inside a Reddit post (Reddit Daily Games Hackathon, Devvit Web). Entry #2 alongside Paanai (`D:\Projects\2-In-Progress\paanai`), which always comes first. Spec: `D:\Projects\3-Ideas-and-Research\reddit-daily-games\Mandaadi_Project_Report_v2.md`. Read `PROGRESS.md` first.

## Hard rules
- NEVER run `devvit publish` or the `launch:AFTER-DEC-9-ONLY` script before 9 Dec 2026 (hackathon rule). `devvit upload` / `devvit playtest` are fine. NEVER `git push` unless asked.
- `src/shared/core` is deterministic: integers only. No Math.sin/cos/atan/exp/pow/log/random/hypot, no Date (ESLint enforces it). Trig via `trig.ts` (tables generated by `npm run gen:trig`). The server will replay input logs with this same code, so any change to `boat.ts` / `wind.ts` / `course.ts` must keep `npx vitest run` green and update tests on purpose.
- All tuning numbers for feel live in `TUNE` and `POLAR` in `src/shared/core/boat.ts`.
- All Devvit access goes through `src/server/platform` (devvit.ts real, memory.ts harness/tests). Redis keys only from `src/server/store/keys.ts` (to be added), no plain sets/lists.
- Inline splash (`splash.html`): no three.js, no `touch-action:none`, no inner scroll, taps only. Expanded view only from a click.
- Client makes no external requests; fonts in `public/fonts`, everything else procedural (no image or audio files). No inline `<script>` (Reddit CSP): loader lives in `public/boot.js`.
- Art: built in code, nothing AI-generated. Look = sunny aerial view of the Coromandel coast: turquoise shallows, coconut palms, traditional painted fishing boats (vallam) with a lateen sail. Do not use anything from the 2026 film *Mandaadi* (posters, stills, logo).
- UI copy: no emojis. 16px+ text, 44px+ targets, tack button 76px. Design at 360-390px wide first.

## Stack
Devvit Web 0.15.3, Node 24, Vite 8, TypeScript 6, Preact + Signals, three.js 0.187, Hono 4.13, Vitest 5, Playwright 1.65.0 (pinned: matches the browsers already installed).

## Commands
- Tests: `npx vitest run` (run from `D:\...` with an uppercase drive letter in PowerShell; a lowercase `d:` cwd loads vitest twice and fails with "reading 'config'").
- Types / lint / build: `npx tsc --build`, `npm run lint`, `npx vite build`.
- Local play: `npm run harness` then http://127.0.0.1:5173/race.html?user=alice (feed card: /splash.html).
  - `?autopilot=1` sails your boat with the autopilot; `?view=x,y,yawDeg,halfWidth` freezes the camera for art stills; `?dpr=1` forces pixel ratio.
- Screens: `node tools/shoot.mjs` (start, countdown, cone, tack, map), `node tools/e2e.mjs` (autopilot full race + finish card), `node tools/view.mjs out.png "x,y,yaw,hw"`, `node tools/perf.mjs 4` (fps at 4x CPU throttle). Output in `.mandaadi/` (gitignored).
- Trace the core: `npx tsx tools/trace.ts [1|-1]`.

## Layout
- `src/shared/core`: fixed, trig(+Table), course, wind, boat (step + rules), inputs (codec), simulate, pilot (autopilot / Harbourmaster).
- `src/shared/content/courses.ts`: hand-made courses.
- `src/client/race`: game loop (`game.ts`), HUD (`Hud.tsx`, `hudState.ts`), entry `main.tsx`.
- `src/client/three`: water shader, islands + palms + mainland, boat model, marks, effects (cone, wake), camera.
- `src/client/app/audio.ts`: Web Audio synthesis. `src/client/input/steer.ts`: drag/keys/double-tap.
